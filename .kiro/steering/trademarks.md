# Marques — règles de prudence (5.4)

Ce n'est pas un avis juridique : ce sont des règles de prudence vérifiées par
`scripts/guards/run_all.py` et par le hook `trademark-guard`.

- Les mots désignant le logiciel d'origine, son langage, son éditeur et sa
  machine **n'apparaissent jamais** dans : le nom du produit, son logo, son
  nom de domaine, le nom du langage, les libellés de l'interface, le code
  (`apps/`, `packages/`), les piles (`stacks/`) ni le jeu d'évaluation.
- `README.md`, `docs/` et `.kiro/` peuvent dire d'où vient l'idée, en une
  phrase factuelle : « inspired by a 1987 card-stack tool, a discontinued
  product; not affiliated with or endorsed by its publisher ».
- Aucune icône, police, trame, son ni pile d'origine n'est reprise. Les polices
  sont sous licence libre, et leur licence est citée dans `docs/`.
- Le langage Murmur est écrit à partir de zéro : il ressemble à son ancêtre par
  ses tournures, pas par son texte. Aucun passage de documentation d'un tiers
  n'est recopié, ni dans le dépôt ni dans les consignes données au modèle.
- Dans la vidéo de soumission : aucune capture du logiciel d'origine, aucune
  marque de tiers à l'image, aucune musique protégée.
